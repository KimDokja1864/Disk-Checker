СМЕНА В «ДИСКОВОДЕ» — проект игры
==================================

ЧТО ЛЕЖИТ В ПАПКЕ
  index.html     игра. Её трогать не нужно.
  assets.js      сюда прописываются картинки, персонажи и звуки.
  dialogs.js     диалоги в конце смены (обычный текст).
  assets/
    layers/      слой 1 (фон) и слой 3 (стол, вид от Никиты)
    npc/         персонажи (слой 2)
    sounds/      свои звуки (по желанию)
    ui/          кадры для экранов: улица, комната, шаурма, плакат, финал

КАК ЗАПУСТИТЬ У СЕБЯ
  Распакуйте архив целиком и дважды щёлкните index.html. Работает в
  Chrome, Firefox, Edge. Сервер не нужен. После правки assets.js или
  dialogs.js обновите страницу (F5).
  Шрифты подгружаются из интернета; без сети будут запасные.

СЛОИ (снизу вверх)
  1. Фон            assets/layers/1_background.jpg     поле background
  2. Персонажи      assets/npc/*.png                   список npcs
                    (лампы, пол и тени рисует игра)
  3. Стол (вид от Никиты)  assets/layers/3_desk.png    поле desk
     PNG с прозрачным окном посередине. Всё непрозрачное закрывает
     персонажей, они стоят за столом.
  Подгонка: charScale (размер) и charY (сдвиг). Тени лежат на полу под
  ногами: если стол их закрывает, поднимите персонажей, charY отрицательный.

КАК ДОБАВИТЬ ПЕРСОНАЖА
  1. Положите PNG в assets/npc/.
  2. Добавьте строку в npcs внутри assets.js:
       { file: "assets/npc/schoolgirl_01.png", gender: "f", age: 15 },
  3. Обновите страницу. Если путь неверный, на первом экране появится
     красное сообщение.
  Каждая картинка привязана к своему описанию: школьница с age 15
  появится только как подросток, и Никита скажет «на вид около 15».
  Нужен «выглядит старше своих лет»: добавьте look, например
  { age: 17, look: 22 }.
  Рекомендуется: прозрачный фон, полный рост, лицом к зрителю, одна и
  та же высота у всех, ноги на одном уровне (низ картинки = пол),
  размер около 420×520 px, без теней и пола. Минимум 12–15 персонажей,
  среди них 3–4 подростка и 2–3 пожилых.

КУДА ЗАКИДЫВАТЬ ИГРУ, ЧТОБЫ ДРУГИЕ ИГРАЛИ
  Папка целиком — это сайт. Подойдёт любой хостинг статических файлов.
  • itch.io: создайте проект, тип «HTML», загрузите zip этой папки
    (index.html должен лежать в корне архива), отметьте «This file will
    be played in the browser».
  • GitHub Pages: загрузите папку в репозиторий, Settings → Pages →
    выбрать ветку main.
  • Netlify Drop (app.netlify.com/drop): перетащите папку в окно.
  • Свой сайт: загрузите папку по FTP, ссылка будет вида
    ваш-сайт/папка/index.html.
  Ссылка в чате Claude (публикация) картинки из файлов не подхватит:
  там блокируются внешние файлы. Для файлов используйте эту папку.

ПОЛЕЗНОЕ
  • Прогресс не сохраняется, игра проходится за один присест. Сохраняется
    только настройка звука.
  • Настройки сложности лежат вверху index.html в блоке CONFIG: с какого
    дня открываются документы и купюры, штрафы по дням, бесплатные
    нарушения, длительность посетителя.
